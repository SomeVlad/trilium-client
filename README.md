# trilium-client

Независимый Android-клиент для [Trilium Notes](https://github.com/TriliumNext/Trilium). Подключается к вашему серверу через ETAPI.

[Скачать APK](https://github.com/SomeVlad/trilium-client/releases/latest) · [Руководство](docs/guide.md) · [Участие в разработке](CONTRIBUTING.md)

## Возможности

- Дерево заметок, папки, клоны, поиск по библиотеке и внутри заметки.
- Визуальное редактирование HTML и Markdown, редактирование кода.
- Чтение, редактирование и поиск офлайн с последующей синхронизацией.
- Добавление изображений и файлов с телефона, просмотр и отправка вложений.
- История версий на сервере с просмотром и восстановлением.
- Светлая и тёмная тема по настройке системы.
- Русский и английский интерфейс с ручным выбором языка. Начальный язык определяется автоматически; для неподдерживаемых языков используется русский.

## Подключение

Установите APK на **Android 9+**, введите полный HTTPS-адрес сервера и пароль, нажмите **Подключиться**. Вместо пароля можно использовать ETAPI-токен из настроек Trilium. Имя пользователя не требуется, пароль не сохраняется.

Подробности об HTTP, офлайн-режиме, ограничениях синхронизации и поддерживаемых заметках — в [руководстве](docs/guide.md).

## Сборка

Нужны **JDK 17**, **Android SDK 36** и переменная `ANDROID_HOME` либо путь `sdk.dir` в `local.properties`.

```sh
./gradlew :app:assembleDebug
```
