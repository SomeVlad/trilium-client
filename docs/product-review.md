# Продуктовое ревью 0.6.5

Подготовка совместимости с Trilium 0.107.0, 12 ноября 2026 года. Независимое ревью кода: sol 6.1 max; синтетические данные, Android API 36.

Код подтверждения появляется только по требованию сервера. Принимаются одноразовые и резервные коды; после отправки поле очищается, при смене реквизитов запрос кода сбрасывается. Вход токеном сохранён.

Вставки заметок, фрагментов и файлов показываются ссылками с подписью. Исходный HTML остаётся в редакторе, включая старые `section.include-note`, подписи, вкладки и параметры вставок. Полного отображения новых виджетов Trilium нет: ссылки на блоки открывают заметку, встроенные рисунки — файл.

Удаление используемого вложения откладывается; неполный каталог блокирует независимое копирование. Изображения заметок с рисунками меняются в Trilium, поскольку рисунок ссылается на имя файла.

Ревьюер лично просмотрел два снимка формы кода RU/EN и вставки в светлой/тёмной теме: подписи, ссылки, поле кода и кнопка подключения читаемы. Блокирующих замечаний в проверенном изменении нет. Это снимки компонентов, не всей навигации.
