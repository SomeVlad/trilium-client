# Проверки 0.6.0

Приёмка 28–29 октября 2026 года на эмуляторе Android API 36 и искусственных данных.

- **253 JVM-теста**, Android lint, **19 тестов CI** и **9 JavaScript-проверок** прошли. GitHub Actions проверен actionlint.
- Архитектурный и продуктовый ревьюер проверил операции с деревом, очереди, восстановление после сбоев и **40 скриншотов**: русский/английский, светлая/тёмная тема, основные новые окна и настоящая MainActivity.
- **61 Android-проверка прошла**: Share, сохранение перед сменой редактора, курсорные ссылки и вложения, возврат из камеры/выбора файла, массовые действия, сортировку, корзину, сравнение версий и диаграммы. Готовность диаграммы подтверждается видимыми пикселями и подписями, а не только загруженным DOM.
- Повторная доставка Share и запрос синхронизации во время старого HTTP 503 не дублируют текст или файл. Копия дерева проверяет полноту локальных данных до создания первой заметки.
- Через публичный HTTPS-вход Trilium **0.106.0** проверены клонирование и повтор запроса, перенос, порядок, корзина/восстановление, переименование и удаление вложения. Только собственные временные QA-заметки; они удалены, личные заметки не менялись.
- Источники диаграмм, карты исходного кода, шрифты и лицензии включены в проверку релизного архива. Данные сервера, токен и ключ подписи в репозиторий не входят.

Физический OnePlus и Android API 28 в этом выпуске не проверялись. Границы ETAPI и офлайн-режима описаны в [руководстве](guide.md).
