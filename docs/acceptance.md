# Проверки 0.6.5

12 ноября 2026 года: Trilium **0.107.0** с отдельной синтетической базой и эмулятор Android API 36, 360 dp.

- 299 JVM-проверок без ошибок, включая один интеграционный тест настоящего сервера: TOTP/резервный код, CRUD, вложения, история, восстановление и отправка офлайн-черновика после перезапуска.
- Android lint (debug/release) и 29 локальных проверок автоматизации релизов прошли.
- 16 Android-сценариев: вход и смена языка, отсутствие секретов в saved state, повторное редактирование вставок, ID блоков при Enter/undo, языки встроенного кода, переходы по ссылкам, поворот экрана и повторный вход с сохранением черновика.
- Проверены новая документация сервера, защита используемых вложений и копирования при неполном каталоге. Синтетические объекты интеграционного теста удалены, отсутствие независимо подтверждено через ETAPI.
- Подписанный APK прошёл вход паролем и резервным кодом на настоящем 0.107.0, создание, повторную правку, синхронизацию и открытие заметки; тестовая заметка удалена.
- Подписанный APK: пакет `ru.vlad.triliumnotes`, версия `0.6.5`, код `25`; редактор в APK совпадает с исходниками. Пакеты диаграмм не изменились.

Это локальная подготовка, не результат GitHub Actions. Физический OnePlus и API 28 не проверялись; полной повторной приёмки всех экранов не было. [Продуктовое ревью](product-review.md) · [Ограничения](guide.md).
