# Проверки 0.5.0

Проверка от 25 октября 2026 года. Android-проверки выполнены на эмуляторе API 36 с искусственными данными.

- **184 JVM-теста**, Android lint и **15 тестов CI** прошли без ошибок. Конфигурация GitHub Actions проверена actionlint.
- **24 функциональные Android-проверки** прошли: редактор, поиск в HTML/Markdown и исходном тексте, история, выбор изображений и файлов, повтор загрузки после сбоя и сохранение результата выбора при обновлении редактора.
- Отдельная Android-проверка сняла восемь экранов поиска и истории на русском и английском для визуального ревью.
- Восстановление версии проверено при неотправленных правках, конфликте, ошибке записи на диск, сетевом сбое и ожидающем вложении. До замены текста создаётся серверная версия текущего состояния.
- Через публичный HTTPS-вход Trilium 0.106.0 проверены загрузка PNG и TXT с русскими именами, скачивание байт в байт, создание и чтение версий, восстановление заголовка и текста. Временные тестовые заметки удалены; личные заметки не менялись.
- Пункт лицензий удалён из интерфейса; файлы лицензий и уведомлений зависимостей сохранены в APK и исходниках.

Физический телефон и API 28 в этом выпуске не проверялись. История требует поддержки соответствующих методов ETAPI сервером.
