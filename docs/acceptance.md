# Проверки 0.6.2

29 октября 2026 года, эмулятор Android API 36, искусственные заметки и отдельный тестовый сервер.

- **253 JVM-теста**, Android lint и **19 тестов CI** прошли.
- **68 регрессионных Android-проверок** прошли. Не запускалась одна дополнительная проверка личных файлов: они не использовались в тестовой среде.
- Проверены область действия удаления, подтверждение и отмена, сохранение выбора, возвращение файла из системного диалога, поиск адресата и отсутствие записи до «Сохранить».
- Проверка с настоящей клавиатурой и шрифтом 130% подтверждает полную видимость названия, причины ошибки и кнопок. Нативная пауза видео и внешняя кнопка согласованы.
- Виджет и новое содержимое Share открывают нужный экран из настроек; обычный возврат в приложение сохраняет настройки открытыми.
- Продуктовый ревьюер проверил изображения экранов и смысл действий: [охват и исправления](product-review.md). Матрицы включают русский/английский, светлую/тёмную тему, загрузку, ошибки, пустые состояния и шрифт 130%.
- Подписанный выпуск проходит CI; скачанные APK и исходники проверяются по контрольным суммам, сертификату, версии и точному коммиту.

Физический OnePlus и Android API 28 не проверялись. [Ограничения клиента](guide.md) · [Команды проверок](../CONTRIBUTING.md) · [Релизы](../ci/README.md).
