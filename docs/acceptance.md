# Проверки 0.6.4

29 октября 2026 года, отдельный эмулятор Android API 36, 360 dp, искусственные заметки.

- 278 JVM-тестов, Android lint и 29 тестов CI. Проверяются сохранение закреплений, старые настройки, изоляция серверов и отсутствие серверных изменений при закреплении.
- 13 Android-проверок: закрепление/открепление, независимость избранного, три сортировки, ручной порядок, клоны, папки, поиск и область действия меню.
- Визуальное ревью: русский/английский, светлая/тёмная тема, шрифт 130%, длинные названия с булавкой и звездой. [Результат ревью](product-review.md).
- Перед доставкой проверяются подписанный APK, скачанные исходники и контрольные суммы; обновление с 0.6.3 должно сохранить избранное, а закрепление — пережить перезапуск без сети.

Физический OnePlus и API 28 не проверялись. Остальные экраны не проходили повторную полную визуальную приёмку в этом выпуске. Предыдущие результаты сохранены в истории Git.
