# Руководство

Клиент для Android 9+ подключается к вашему серверу Trilium через ETAPI.

## Подключение и язык

- Укажите полный HTTPS-адрес, включая подпуть прокси, и пароль либо ETAPI-токен. Имя пользователя не требуется.
- HTTP включается отдельно. Нужен действительный TLS-сертификат; страницы входа прокси и CAPTCHA приложение не обходит.
- Пароль не сохраняется; токен шифруется через Android Keystore.
- Начальный язык берётся из системы: русский или английский, иначе русский. На экране входа и в **Настройках** доступны только **Русский** и **English**; выбор сохраняется после перезапуска. Содержимое заметок не переводится.

## Офлайн и данные

- Сначала скачайте заметки и вложения с подключением к серверу. Фоновую синхронизацию Android может откладывать.
- Черновики сохраняются на телефоне и отправляются после восстановления связи. При конфликте локальный текст сохраняется отдельно.
- Выход удаляет токен, но оставляет кэш и очередь изменений для повторного входа на тот же URL. Разные URL используют отдельные данные.
- Удаление приложения стирает локальные данные; Android-бэкап отключён. Перенос старого кэша подтверждайте только для исходного сервера.
- Удаление заметки затрагивает её клоны и потомков без других родителей. Отмены удаления в клиенте нет.
- ETAPI не поддерживает атомарную проверку версии при записи: одновременные правки в разных клиентах могут столкнуться.

## Ограничения

- Текстовые/API-ответы и встроенные ресурсы редактора ограничены **20 МиБ на ответ**. Двоичные вложения скачиваются прямо на диск.
- Текстовая библиотека хранится в JSON-кэше в памяти; очень большие библиотеки могут работать медленно.
- Холсты, карты связей, защищённые заметки и специальные разделы открывайте в Trilium; разблокировка выполняется там же. Mermaid редактируется как исходный текст, серверные команды и виджеты не исполняются.
- Публичные встроенные изображения должны использовать HTTPS; относительные ресурсы заметок загружаются с авторизацией ETAPI.
