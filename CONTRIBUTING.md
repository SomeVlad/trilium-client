# Участие в разработке

Основная ветка — `master`. Для крупной правки сначала опишите желаемое поведение в issue; небольшие исправления присылайте отдельными pull request.

Для сборки нужны JDK 17, Android SDK 36 и `ANDROID_HOME` либо `sdk.dir` в `local.properties`:

```sh
./gradlew -PdemoBuild=true :app:testDebugUnitTest :app:lintRelease :app:assembleDebug
./gradlew -PdemoBuild=true :app:connectedDebugAndroidTest
```

Инструментальные тесты запускайте на отдельном эмуляторе или тестовом устройстве с вымышленными данными: они проверяют хранилище, синхронизацию и жизненный цикл приложения.

В pull request укажите результат для пользователя и выполненные проверки. Изменения сохранения, синхронизации и удаления проверяйте поведением, а не только скриншотами.

Не публикуйте токены, личные адреса серверов, заметки, ключи подписи и приватные тестовые данные. Сервер и вход настраиваются в приложении; флаг `demoBuild` лишь отключает локальные параметры подписи.
