Сборка офлайн-просмотра диаграмм

Версии закреплены в package.json/package-lock.json:
- Mermaid 11.17.2: официальный рендерер, строгий режим.
- @excalidraw/excalidraw 0.18.1: официальные restoreElements/exportToSvg.
- React/React DOM 18.3.1: зависимости Excalidraw.
- esbuild 0.28.2: сборщик.

Нужен Node 22; проверенная сборка использовала 22.16.0:
  cd scripts/diagrams
  npm ci --ignore-scripts --no-audit --no-fund
  npm run build
  npm test

Сборка создаёт JavaScript IIFE с синтаксической целью Chromium 71,
локальные шрифты Excalidraw и уведомления зависимостей в
app/src/main/assets/diagrams/vendor. На устройстве CDN/npm не используются;
нужный пакет Mermaid или Canvas скачивается из закреплённого GitHub Release
при первом использовании, затем работает локально без сети. Шрифты берутся локально
и встраиваются официальным SVG-экспортёром Excalidraw.

Полный vendor сохранён в репозитории и архиве исходников. В APK входят только
оболочка, viewer.js, packages.json и уведомления; библиотеки и все шрифты
упаковываются отдельно командой из корня репозитория:
  python3 scripts/package-diagrams.py /tmp/diagram-packages
Команда проверяет sources.lock.json и закреплённый packages.json. ZIP содержит
пути относительно diagrams/vendor, исходные JS/шрифты и оба файла уведомлений.
Формат ZIP_STORED, фиксированные порядок, дата и права дают одинаковые байты
без зависимости от zlib. Начальные URL закреплены за тегом v0.6.3, а не latest.

После намеренного изменения библиотек выполните npm run build, затем из корня:
  python3 scripts/package-diagrams.py /tmp/diagram-packages --write-manifest --package-version vMAJOR.MINOR.PATCH
Укажите новый стабильный тег, в котором будут опубликованы ZIP и исходники.
Пакеты с неизменившимися байтами сохраняют прежние версию, URL и SHA-256;
обычный выпуск приложения не обновляет манифест и не сбрасывает скачанный пакет.

Исходники и проверка происхождения:
- maps/: полные source maps с sourcesContent и метаданные esbuild; в APK
  не входят, сохраняются в архиве исходников.
- sources.lock.json: npm-архивы с integrity, архивы исходников и SHA-256
  каждого собранного файла. upstream-sources.json закрепляет коммиты.
- preferred-sources/: оригинальный TypeScript mermaid-to-excalidraw.
  Его опубликованная карта не содержит sourcesContent; build.mjs дополняет
  её этими исходниками, сохраняя код рендерера.
- UPSTREAM_LICENSES.txt: лицензии шрифтов из исходников и официальных
  репозиториев; URL и хеши указаны в font-license-sources.json.

Эти файлы и закреплённые архивы включаются в выпуск исходников. Лицензионные
тексты остаются файлами; экран «О приложении» для них не добавляется.

WebView получает только локальные ресурсы диаграмм: без токенов, сервисов,
записи заметок, доступа к файлам/content URI и сетевых загрузок. Переходы,
серверные ресурсы и удалённые картинки блокируются. Ссылки и веб-вставки
Excalidraw удаляются; встроенные картинки допускаются только растровые.
Строгий Mermaid отключает действия по нажатию и HTML-метки. Доступны
перемещение, масштаб жестами/колесом/кнопками и вписывание в экран.

Исправления зависимостей от 28.10.2026 закреплены через overrides:
lodash-es 4.18.1, NanoID 3.3.18/5.1.16, KaTeX 0.18.2. Разбор и проверки —
в SECURITY_REVIEW.txt. После смены bundles нужны также Android-тесты.
